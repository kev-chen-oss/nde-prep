# Day 1 · Network Devices
Date: 2026-11-23

## Key ideas (in my own words)
- The same device can be a client in one situation and a server in another.
- A switch connects end hosts within the same LAN. It cannot connect different LANs by itself.
- A router connects different LANs, so it is what sends our data out to the Internet. Routers have fewer ports than switches.
- A firewall decides which traffic can enter or leave, based on rules. A network firewall protects the whole network; a host-based firewall protects one device. Using both gives an extra layer of defense.

## Terms
| Term | One-line meaning |
|---|---|
| Computer network | A digital telecommunications network which allows nodes to share resources. |
| Node | Any device connected to a network, e.g. a PC, server, switch or router. |
| Cable | A physical connection that carries signals between two devices. |
| Interface / Port | The socket on a device where a cable plugs in. |
| End host / Endpoint | A device that sends or receives data, such as a PC, phone or server. |
| Network device | A device that moves or filters traffic between end hosts, such as a switch, router or firewall. |
| Client | A device that requests a service from a server. |
| Server | A device that provides services to clients and responds to their requests. |
| LAN | Local Area Network: a network in a small area, like a home or an office. |
| Switch | A device with many ports that connects end hosts in the same LAN. |
| Router | A device that connects different LANs and forwards data between them, including over the Internet. |
| Network firewall | A hardware device that monitors and controls traffic entering and leaving a network, based on configured rules. |
| Host-based firewall | Software that filters traffic entering and leaving one host, such as a PC. |
| NGFW | Next-Generation Firewall: a firewall with more advanced filtering features. |

## Questions
- What is an "end host"? → A device at the edge of the network that sends or receives data (PC, phone, server). Switches and routers are not end hosts; they only pass data along.
